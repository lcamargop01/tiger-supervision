# tiger-supervision

Public reference site for advanced-practice clinician supervision and collaborative practice requirements, by US state.

- Static site. No build step.
- Deploys to Cloudflare Pages.
- Data: `data/states.json` (populated by compliance research; updated incrementally).
- Map: D3 + TopoJSON (us-atlas@3 states-10m).
